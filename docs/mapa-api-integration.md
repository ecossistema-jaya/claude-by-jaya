# Adult self-knowledge map — API integration

## Approved scope

Integrate the revised map with the existing Gemini engine, preserve its visual identity, course navigation, symbolic tarot, download and print. Interpret everyday adult experiences; professional/income interpretation is opt-in. No official instrument scores or invented personality percentages.

## Implementation and acceptance

- `docs/mapa-autoconhecimento-v0.html` is the editable prototype. `scripts/build-aulas.mjs` generates its protected public copy and the lesson 4 entry link.
- `POST /api/mapa/analyze` inherits the course middleware authentication. The server owns the prompt and validates canonical answers, evidence IDs and model output.
- Five personal reflection cards, synthesis and a practical experiment are generated by Gemini. Professional text is separately conditional; no professional answers enter the prompt after opt-out.
- The prominent Zone of Genius map contains four qualitative zones (genius, excellence, competence and development), a provisional hypothesis, and answer references. Zones without evidence use a server-controlled missing-data message. Previously saved readings can be updated without repeating the questionnaire.
- Charts are deterministic: recurrence bars and a three-column activity matrix. Tarot remains a separate symbolic rule, not an AI diagnosis.
- The learner explicitly chooses “Gerar leitura com IA” after disclosure. The name field is excluded. Saved analysis is bound to the exact answer snapshot and stops being current when answers change. Loading, retry, authorization errors, missing evidence and provider failure preserve local answers.
- Download and print include the rendered reading. Download strips interactive generation controls.

## Validation

- `node scripts/test-mapa.mjs`: syntax, UI/server schema parity, invalid input, evidence validation, opt-out and malformed model responses passed.
- `npx tsc --noEmit`: passed.
- Browser: real Gemini generation with fictional responses passed, and the generated reading survived reload. No user answers were sent during the test.
- Local HTTP checks: inadequate input 422, foreign origin 403, oversized body 413.
- Static review completed without blocking findings. Production authentication was inspected, not exercised with a live deployed session.
- File download/OS print dialogs remain unverified in the embedded browser, as recorded in the earlier prototype review.

## Local preview and boundaries

`node --use-system-ca scripts/preview-mapa.mjs` serves only the map and its local test API on `127.0.0.1:4180`, with strict Host/Origin and JSON checks. It reads local environment credentials without exposing them to the frontend. It is a development harness, never a deployment entry point. Production uses Next and course authentication.

The existing course preview at port 4012 redirects to port 4180 to retain the learner's stored answers. Both servers must run for round-trip navigation. No deployment or database change was performed. Existing in-memory rate limits remain per process, not a distributed quota.
